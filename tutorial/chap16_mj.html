16 Hecke operators for \(\Gamma_0(N)\) in \(SL_3(\mathbb Z)\) (by Giulia Orrù)

16.1 The Hecke operator \(E_p\)

Let \(\alpha_p\) be the matrix defining the Hecke operator \(E_p: H^3(\Gamma_0(N), \mathbb C) \to H^3(\Gamma_0(N), \mathbb C)\), for prime \(p\) not dividing \(N\), with

\[\alpha_p = \left(\begin{array}{ccc} p & 0 & 0\\ 0 & 1 & 0\\ 0 & 0 & 1 \end{array}\right)\]

The double coset \(\Gamma_0(N)\alpha_p \Gamma_0(N)\) can be decomposed as \( \coprod_i \beta_i \Gamma_0(N)\). For \(N = 53\) and \(p = 2\) there are \(p^2 + p + 1 = 7\) representatives \(\beta_i\):

gap> HAP_Gamma0_SL3ZHeckeCosetReps(53,2);
[ [ [ 1, 0, 0 ], [ 0, 1, 0 ], [ 0, 0, 2 ] ], 
  [ [ 1, 0, 0 ], [ 0, 1, 0 ], [ 0, 1, 2 ] ], 
  [ [ 1, 0, 0 ], [ 0, 1, 0 ], [ 53, 0, 2 ] ], 
  [ [ 1, 0, 0 ], [ 0, 1, 0 ], [ 53, 1, 2 ] ], 
  [ [ 1, 0, 0 ], [ 0, 2, 0 ], [ 0, 0, 1 ] ], 
  [ [ 1, 0, 0 ], [ 53, 2, 0 ], [ 0, 0, 1 ] ], 
  [ [ 2, 0, 0 ], [ 0, 1, 0 ], [ 0, 0, 1 ] ] ]

The function Gamma0_SL3ZHeckeOperator(N,p) computes the action of \(E_p\) over \(\mathbb Z\) on \(H_0(\Gamma_0(N),St)\), using the presentation of Section 15.3. It returns the matrix Tfree of \(E_p\) on the free part, whose eigenvalues are those of \(E_p\) on \(H^3(\Gamma_0(N),\mathbb C)\), and the matrix Ttorsion of its action on the torsion part. For example, for \(N=11\) and \(p=2\) the group \(H_0(\Gamma_0(11),St)\) is free of rank \(2\), and the matrix of \(E_2\) is:

gap> Gamma0_SL3ZHeckeOperator(11,2).Tfree;
[ [ -3, -1 ], [ 0, 2 ] ]

16.2 Characteristic polynomial of \(E_p\)

The following commands compute the factored characteristic polynomials of \(E_p: H^3(\Gamma_0(11),\mathbb C) \to H^3(\Gamma_0(11),\mathbb C)\), for \(p = 2, 3, 5, 7\):

gap> Factors(CharacteristicPolynomial(Gamma0_SL3ZHeckeOperator(11,2).Tfree));
[ x_1-2, x_1+3 ]
gap> Factors(CharacteristicPolynomial(Gamma0_SL3ZHeckeOperator(11,3).Tfree));
[ x_1-8, x_1+2 ]
gap> Factors(CharacteristicPolynomial(Gamma0_SL3ZHeckeOperator(11,5).Tfree));
[ x_1-26, x_1-6 ]
gap> Factors(CharacteristicPolynomial(Gamma0_SL3ZHeckeOperator(11,7).Tfree));
[ x_1-47, x_1+13 ]

Note that, in each case, the eigenvalues are exactly \(p^2+b_p\) and \(1+pb_p\), where \(b_p\) is the \(p\)-th coefficient of the newform of weight 2 and level 11 (associated with the elliptic curve 11a). They correspond to the noncuspidal classes that arise from the Eisenstein liftings (see Example 3.4 of [vGvdKTV97]). Moreover, when \(N\) is prime, one has [AGG84]:

\[\dim H^3(\Gamma_0(N),\mathbb C) = \dim H^3_{cusp}(\Gamma_0(N),\mathbb C) + 2\dim S_2(N),\]

where \(S_2(N)\) is the space of weight two cusp forms for \(\Gamma_0(N) \subset SL_2(\mathbb Z)\). For \(N=11\) we have \(\dim H^3(\Gamma_0(11),\mathbb C)=2\) (Section 15.4) and \(\dim S_2(11)=1\), so there are no cuspidal classes.

For \(N = 53\) we have \(\dim H^3(\Gamma_0(53),\mathbb C)=10\) and \(\dim S_2(53)=4\), so \(\dim H^3_{cusp}(\Gamma_0(53),\mathbb C)=2\). The following computes the factored characteristic polynomial of \(E_2\) for \(N = 53\):

gap> Factors(CharacteristicPolynomial(Gamma0_SL3ZHeckeOperator(53,2).Tfree));
[ x_1-3, x_1+1, x_1^2+4*x_1+15, x_1^3-11*x_1^2+37*x_1-37, x_1^3-x_1^2-13*x_1+5 ]

The linear and cubic factors are the Eisenstein liftings of the four newforms in \(S_2(53)\). The remaining factor \(x_1^2+4x_1+15\) comes from the cuspidal part: its roots \(-2\pm\sqrt{-11}\) are the eigenvalue \(a_2\) in Table 2 of [vGvdKTV97] and its complex conjugate.
